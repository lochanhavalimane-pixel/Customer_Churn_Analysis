📊 Telco Customer Churn Analysis & Retention StrategyAn end-to-end data analytics project focused on evaluating customer attrition (churn) within a telecommunications enterprise. By processing and analyzing demographic, operational, service-level, and financial data across 7,048 customer accounts, this project identifies key churn drivers and delivers actionable retention strategies to maximize Customer Lifetime Value (CLV).   📌 Executive SummaryAcquiring new customers in the telecom industry costs up to 5x more than retaining existing ones. This project analyzes churn behavior to pinpoint vulnerable customer cohorts, quantify service-level risk factors, and establish an automated Power Query data transformation pipeline to power an interactive executive report.   Key MetricsTotal Customers: 7,048   Overall Churn Rate: 26.52%   Total Churned Accounts: 1,869   High-Risk Active Segment: 633 accounts   📁 Repository Structuretelco_churn_unclean.csv — Raw transactional datasetCustomer Churn Analysis.pbix — Power BI Project File / DashboardTelco Customer Churn Report.pdf — Executive Summary PDF ReportREADME.md — Project Documentation🧹 Data Cleaning & Transformation (Power Query ETL)Before visual modeling in Power BI, raw data (telco_churn_unclean.csv) underwent structured data transformation in Power Query to guarantee analytical accuracy:   TotalCharges Blank & Error Handling: Handled empty and non-numeric entries corresponding to new accounts with tenure < 1 month. Converted column type to Decimal and imputed 0 or null for new accounts.   MonthlyCharges Normalization: Stripped currency symbol prefixes ($, ₹) across text strings and explicitly cast the column to Decimal Number.   Contract Column Standardization: Standardized inconsistent text casing and formatting (e.g., unified "month to month" and "Month-to-month" into "Month-to-month").   Whitespace Elimination: Applied Transform -> Format -> Trim across all categorical text attributes (Payment Method, Internet Service, gender, Churn) to remove leading/trailing spaces.   Logical Consistency & Conditional Mapping: Enforced strict domain business logic:   If PhoneService = 'No', set MultipleLines = 'No'.   If InternetService = 'No', set all add-on services (OnlineSecurity, DeviceProtection, TechSupport, StreamingTV, etc.) to 'No'.   💡 Core Findings & Risk Profiles1.
